# AI 质检系统使用说明 · 普通用户

> 适用版本：v0.0.13 起（2026-08-11）。文中标注 📷 的截图槽位待补充，清单见文末[附录](#附录截图槽位清单)。
> 管理员功能（项目创建 / 用户管理 / 模型管理 / 队列监控 / 健康巡检）见《使用说明 · 管理员》。

## 1. 你能做什么

普通用户登录后只看到「项目管理」一个导航入口，在自己被分配的项目内完成日常工作：

- 查看自己所在的项目与项目进度；
- 上传 / 导入题目，编辑题目并保存新版本；
- 对题目发起质检（单题重检 / 批量质检），实时查看进度；
- 查看质检结果：LaTeX 校验、AI 合成题检测、难度分级（L0–L3）、多模型求解与答案比对详情；
- 导出题目列表。

不能做：创建 / 删除项目、管理账号、修改模型与策略配置、查看队列与巡检（这些属于管理员或项目管理员）。

## 2. 登录

📷 **截图槽位 U-01**：登录页（用户名 / 密码输入与错误提示）。

- 账号由管理员或项目管理员下发；登录成功后以会话 Cookie 维持登录。
- 密码复杂度要求：至少 8 位，且包含大写字母、小写字母、数字、特殊字符。
- 账号可能设有有效期；过期或被停用会提示无法登录，请联系管理员。

## 3. 我的项目

📷 **截图槽位 U-02**：普通用户视角的项目管理页（仅项目卡片，无管理操作按钮）。

- 页面展示你被分配到的项目卡片：状态（进行中 / 已暂停 / 已停止）、题目数与完成数、题目目标进度。
- 点击项目卡片进入该项目的题目列表与质检空间。
- 项目由管理员 / 项目管理员创建和维护；若看不到应有项目或项目状态异常，联系项目管理员。

## 4. 题目列表

![题目列表](images/question-list.png)

### 4.1 检索与指标

- 关键词搜索（题目 / 领域）；筛选：全部状态、是否合格、分级状态、难度等级、全部提交人、创建 / 修改日期区间。
- 四张指标卡：全部题目 / 待检测 / 疑似合成 / 合格。
- 列表列：序号、版本、标题、题目类型、学科、领域、知识层级、难度等级、分级状态、知识点、问题预览；操作列含「详情」与删除（删除自己的题目）。

### 4.2 导入题目

📷 **截图槽位 U-03**：导入弹窗（选择 Excel 后显示「解析成功，共 N 道题目」）。

- 点击「导入」选择 Excel 文件；表头固定 8 列：`标题、题目类型、领域、难度、知识点、问题、答案、解题思路`。
- 列顺序无关，名称须完全一致；「问题」为空的行自动跳过。
- 解析成功后分批提交；上传时近乎相同的题目会被本地去重拦截，上传后系统异步做相似题检测。
- 每个账号可能有题目上传上限（由管理员设置），达到上限会提示剩余可上传数量。

### 4.3 批量质检与导出

- 勾选题目后点击「全部质检（已选 N 条）」；未勾选时对当前筛选结果发起。
- 提交后列表顶部出现实时进度条（📷 U-04）：「批量质检：排队 N，运行 N，完成 N/N，人工复核 N」。
- 质检发起后即可查看进度，无需等待；浏览器关闭也不影响后台执行。
- 「导出」将当前列表导出为 Excel。

## 5. 题目详情

![题目详情](images/question-detail.png)

### 5.1 题目内容区（左侧）

- 标题、版本号（v1 / v2 …）、标签（题目类型、知识层级、竞赛 / 知识点标签）；学科 / 领域 / 知识点。
- 题目、参考答案、解题思路以公式渲染展示，各块支持一键复制。
- 「编辑」修改并保存为新版本：版本号 +1，检测状态重置并自动重新质检。
- 右上角「上一题 / 下一题」在列表内快速切换。

### 5.2 质检结果区（右侧）

- **难度分级评测**卡片：状态（已完成 / 运行中 / 评测失败等）与最终定级 L0–L3。
  - 「用量」查看本任务的模型调用明细（Token、耗时、成本）。
  - 「重新检测」对本题发起重检（受账号配额约束）。
- **L0**：LaTeX 格式校验 + AI 合成题检测，展示是否构成正常题目、是否疑似 AI 生成题及置信度与判断依据。
- **L1 / L2 / L3**：每层展示作答模型、运行次数、答对门槛，以及每次独立求解的等价比对结论（等价 / 不等价）。
- 晋级规则：答对次数满足门槛晋级下一层；不满足说明题目过易，退回定级。
- 评测失败或疑似合成时，「质检结果」标题显示问题数角标；展开查看失败原因与依据（📷 U-05），必要时联系管理员人工复核。

## 6. 常见问题

1. **导入 Excel 报错？**
   核对 8 列表头是否与 `标题、题目类型、领域、难度、知识点、问题、答案、解题思路` 完全一致；「问题」为空的行会被跳过。
2. **发起质检报 409？**
   账号日上限 / 月上限 / 月预算或题目上传上限已用完；提示会带剩余配额，次日 / 次月或管理员调高配额后恢复。
3. **改了模型配置，为什么我的任务还是旧模型？**
   模型与策略在任务创建瞬间快照固化；修改配置只影响之后新建的任务，历史任务显示旧模型属预期行为。
4. **质检进度长时间不动？**
   后台会自动重试临时性错误；长时间无进展请联系管理员查看队列监控与健康巡检。
5. **保存新版本后为什么状态重置？**
   新版本意味着题目内容变化，所有检测会重新执行，历史版本结果仍可在版本记录中追溯。
