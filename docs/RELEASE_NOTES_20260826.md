# STEM 题目审核系统 - 发版说明 (Release Notes)

**发布版本**：v1.8.0  
**发布时间**：2026 年 8 月 26 日  
**适用范围**：前端 (`stem-system-frontend`)、后端 API (`stem-system-backend`)

---

## 🌟 版本亮点摘要

本次发布重点推出了**质检任务专有页面与 6:4 左右 Split 响应式布局**，彻底解决了质检任务内容丰富时弹窗拥挤的痛点；同步上线了**全流程 LaTeX 公式语法实时检测与错误拦截**机制，并补齐了**管理员退回理由高亮提示与质检草稿自动预填**等重要协作功能。

---

## 🚀 详细更新内容

### 1. 🖼️ 质检任务专有页面与 6:4 左右 Split 吸顶布局 (Dedicated Task Page)

- **独立专有路由**：
  - 质检任务由原先的弹窗 Modal 全面升级为独立的专有页面路由 `/quality-review-tasks/[id]`。
  - 在【质检任务中心】列表点击【审核任务】/【查看任务】/【复核确认】时，平滑跳转进入独立页面，大幅提升长内容研读的视觉空间。
- **6:4 左右 Split 响应式分栏**：
  - **左侧研读区 (60% 宽度)**：整合受保护防截图遮罩、动态水印、原题目 Card、原参考答案 Card、原解题思路 Card 及题目基本元数据卡片。
  - **右侧质检面板 (40% 宽度，Sticky 视口吸顶)**：面板随页面滚动悬浮吸顶，质检员在下翻阅读推导过程时，可随时在右侧完成判定与输入。
- **管理员复核统一视图**：
  - 管理员亦可在此专有页面中直观查看质检员结论，并一键完成【确认更新答案】、【退回修改】与【驳回结论】操作。

---

### 2. 🛡️ 质检防错机制：LaTeX 公式语法实时检测与拦截 (LaTeX Error Interceptor)

- **多维度规则校验算法 (`validateLatex`)**：
  - 针对【纠正后的答案】与【纠正后的解题思路】，自动检测公式语法：
    - **界定符成对匹配**：单美元 `$ ... $` 与双美元 `$$ ... $$` 数量偶数性校验；
    - **定界符对齐**：行内 `\( ... \)` 与块级 `\[ ... \]` 数量配对校验；
    - **LaTeX 环境闭合**：`\begin{matrix}` 等环境是否与 `\end{matrix}` 一致；
    - **花括号深度嵌套**：`\frac{a}{b}` 中是否存在多余或未闭合的花括号 `{` / `}`；
    - **裸露命令拦截**：识别公式定界符外裸露的 LaTeX 命令（如 `\frac`, `\sqrt`, `\alpha`, `\sum` 等）。
- **前端+后端双重拦截**：
  - 前端在质检员/管理员点击提交时实时拦截，弹出 `LaTeX 公式格式检测未通过` 专用错误弹窗，逐条提示具体错误点；
  - 后端提交 API 同步接入 422 复核，彻底杜绝语法错误公式入库。

---

### 3. 💬 质检协作流闭环：退回理由高亮提示与草稿预填 (Return Reason Alert & Draft Prefill)

- **管理员退回理由高亮提示**：
  - 质检任务被管理员退回修改（`returned`）后，质检员进入质检页面顶部会自动高亮展示红色的 **【管理员退回修改提示】**，完整呈现退回理由（支持 Markdown 与 LaTeX 公式渲染）及退回时间。
- **历史草稿自动带出**：
  - 被退回的任务重新打开时，系统会自动预填质检员上一次提交的“纠正后的答案”、“解题思路”与“质检理由”，方便在原内容基础上快速修改。

---

### 4. ✏️ 编辑器与系统细节优化 (Editor & UX Enhancements)

- **Markdown 编辑器单按钮切换与同行对齐**：
  - 将 `[编辑]` 和 `[预览]` 按钮整合为单个动态切换按钮 `[👁 预览效果 / ✏️ 返回编辑]`，并与标题 Label 在同一水平线上 Flex 对齐。
- **框高度 100% 动态一致**：
  - 输入框 `TextArea` 与预览 `div` 强制设定相同的 `minHeight`，切换模式时 0 页面跳动。
- **越权 URL 直达拦截**：
  - 质检员账号直接在地址栏访问 `/questions/[id]` 时，优雅渲染 Ant Design 403 权限提示，引导其前往【质检任务中心】。
