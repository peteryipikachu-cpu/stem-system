# STEM 题目审核系统发版说明（产品视角精简版）

# v0.1.6

发布日期：2026-08-26 ~ 2026-09-03 (按 Commit 提交日期划分)

**公式标记体系统一转换算法与混用检测**

- **标记体系统一转换 (`normalize_latex_delimiters`)**：提供公式标记体系统一转换算法，支持将行内 `$ ... $` 与行间 `$$ ... $$` 无损规范为标准 LaTeX 体系（`\( ... \)` 与 `\[ ... \]`）或 Plain TeX 体系，数学公式内部与排版 100% 保持零改动，转义货币符号 `\$` 自动保护。
- **跨体系混用检测 (`latex-delimiter-mixed`)**：在 L0 基础检测、上传/编辑入口与前端质检校验中，自动检测全文是否同时混用了老式 `$` 与标准 `\(` / `\[` 定界符。一旦发现跨体系混用立刻阻断并提示统一标准。

**全文本首尾空白字符与多余空行严格校验**

- **全字段 100% 拦截覆盖**：规则拦截（`upload_rule_violations`）、L0 门控与前端 `validateLatex` 全量扩展覆盖【题干】（`question`）、【参考答案】（`answer`）与【解题思路】（`solution`）三大核心文本。
- **防脏格式入库**：检测到文本首尾包含空格、换行符 `\n` 或连续 3 个及以上多余换行符时，自动拦截阻断，确保文本格式干净规范。

**题目大盘与详情页筛选无损保留**

- **筛选条件全量透传与自动还原**：从题目列表页进入题目详情页时，列表页当前的全部筛选条件（搜索关键字、学科、领域、难度等级、合格状态、提交人 ID、日期起止、pageSize 及页码 page）均会自动作为 Query 参数透传至详情页。
- **多通道导航无缝无损**：无论是通过面包屑【题目列表】、详情页“上一题/下一题”导航，还是直接使用浏览器的【后退】按钮，返回列表页时均可 100% 自动解包并还原之前的筛选状态与分页位置。

**全站下拉选择框支持输入过滤与打字搜索**

- **动态拼音/用户名模糊搜索**：题目大盘【全部提交人】下拉框、质检任务【分配质检员】弹窗下拉框以及学科/领域下拉框全面开启输入搜索过滤支持。
- **实时匹配与快速定位**：用户可在下拉框中直接打字输入拼音或用户名关键词，下拉选项列表自动即时匹配并精确定位目标成员。

**版本历史展开表格数据字段补齐**

- **数据丰富化**：历史版本列表接口新增下发 `checkResultCount`（检测项数量）与 `checkSummary`（质检汇总结论）字段。
- **全量显示质检指标**：题目大盘展开版本历史列表时，v1 ~ vN 的各个历史快照均能完整呈现对应的“定级结果”（L0~L4）、“是否合格”、“AI合成检测”与“质检状态”。

**历史版本详情页异步加载崩溃与空指针修复**

- **空指针根因修复**：修复当带有 `?version=x` 历史版本参数访问详情页时，由于用户身份与题目数据在 SWR 异步加载期未就绪引发未捕获 TypeError 空指针崩溃（`This page couldn't load`）。
- **加载体验与空值防护**：顶栏与页面加载全量增加安全加载遮罩与链式空值防护（`currentUser?.role` 与 `question?.currentVersion`），彻底消除了历史版本页面的屏闪与报错。

**题目编辑权限精细化管控与项目状态防护**

- **编辑权限严格管控**：限制题目修改与编辑仅允许全局管理员（admin）和项目管理员（project_admin）操作；对普通用户隐藏编辑按钮及编辑弹窗。
- **项目生命周期约束**：加固项目状态校验。当项目处于暂停 (`paused`) 或 停止 (`stopped`) 状态时，全量禁止对其名下题目进行内容编辑与保存新版本。

**历史质检任务卡片表格自适应与防溢出优化**

- **响应式表格自适应 (`Scroll Fit`)**：重构题目详情页【历史质检任务】卡片内部表格的列宽布局，配置 `scroll={{ x: "max-content" }}` 滚动支持与 `overflowX: "auto"` 剪裁约束。
- **防止文字与操作列溢出**：彻底解决了中窄屏幕下表格“发起时间”、“成本”与“操作（用量）”列超出卡片右侧边界的 UI 缺陷，确保在任意屏幕分辨率下表格均 100% 优雅对齐嵌在卡片边框内部。

**质检任务专有页面与 6:4 左右 Split 响应式布局**

- **独立专有页面路由**：质检任务由原先的弹窗 Modal 全面升级为独立的专有页面路由 `/quality-review-tasks/[id]`。在【质检任务中心】列表点击【审核任务】/【查看任务】/【复核确认】时，平滑跳转进入独立页面，彻底解决原弹窗模式下内容拥挤的痛点。
- **6:4 左右 Split 双栏吸顶布局**：
  - **左侧研读区 (60% 宽度)**：整合受保护防截图遮罩、动态水印、原题目 Card、原参考答案 Card、原解题思路 Card 及题目基本元数据卡片。
  - **右侧质检面板 (40% 宽度，Sticky 视口吸顶)**：面板随页面滚动悬浮吸顶，质检员在下翻阅读推导过程时，可随时在右侧完成判定与输入。
- **管理员复核统一视图**：管理员亦可在此专有页面中直观查看质检员结论，并一键完成【确认更新答案】、【退回修改】与【驳回结论】操作。

**全流程 LaTeX 公式语法实时检测与错误拦截**

- **多维度规则校验算法 (`validateLatex`)**：针对【纠正后的答案】与【纠正后的解题思路】，自动检测公式语法：
  - **界定符成对匹配**：单美元 `$ ... $` 与双美元 `$$ ... $$` 数量偶数性校验；
  - **定界符对齐**：行内 `\( ... \)` 与块级 `\[ ... \]` 数量配对校验；
  - **LaTeX 环境闭合**：`\begin{matrix}` 等环境是否与 `\end{matrix}` 一致；
  - **花括号深度嵌套**：`\frac{a}{b}` 中是否存在多余或未闭合的花括号 `{` / `}`；
  - **裸露命令拦截**：识别公式定界符外裸露的 LaTeX 命令（如 `\frac`, `\sqrt`, `\alpha`, `\sum` 等）。
- **前端+后端双重拦截**：前端在质检员/管理员点击提交时实时拦截，弹出 `LaTeX 公式格式检测未通过` 专用错误弹窗，逐条提示具体错误点；后端提交 API 同步接入 422 复核，彻底杜绝语法错误公式入库。

**质检协作流闭环与草稿预填**

- **管理员退回理由高亮提示**：质检任务被管理员退回修改（`returned`）后，质检员进入质检页面顶部会自动高亮展示红色的【管理员退回修改提示】，完整呈现退回理由（支持 Markdown 与 LaTeX 公式渲染）及退回时间。
- **历史草稿自动带出**：被退回的任务重新打开时，系统会自动预填质检员上一次提交的“纠正后的答案”、“解题思路”与“质检理由”，方便在原内容基础上快速修改。

**Markdown 编辑器与 UI 规范化**

- **编辑/预览单按钮切换与同行对齐**：将 `[编辑]` 和 `[预览]` 按钮整合为单个动态切换按钮 `[👁 预览效果 / ✏️ 返回编辑]`，并与标题 Label 在同一水平线上 Flex 对齐。
- **框高度 100% 动态一致**：输入框 `TextArea` 与预览 `div` 强制设定相同的 `minHeight`，切换模式时 0 页面跳动。
- **越权 URL 直达拦截与规范化**：质检员账号直接在地址栏访问 `/questions/[id]` 时，优雅渲染 Ant Design 403 权限提示；消除质检页面 3 处 Ant Design 控制台 Warning（Spin description、Breadcrumb items、Divider 竖线）。

# v0.1.5

发布日期：2026-08-25 ~ 2026-08-27 (按 Commit 提交日期划分)

**用户复合多角色兼具与下发/批量多选**

- **用户复合多角色**：用户模型全面升级支持多角色兼具（账号可同时具备 `普通用户 + 质检员`、`项目管理员 + 质检员` 或系统主管理员等组合），打破单一角色限制；用户列表中直观展示复合角色标签组。
- **下发与批量账号角色多选**：单账号下发/编辑与批量上传用户弹窗的角色选择框均升级为多选控件（支持选【普通用户】、【质检员】、【项目管理员】）。系统超级管理员（`admin`）作为全局唯一账号，下发时不开放为常规角色勾选。
- **纯质检员配额输入框动态隐藏**：在单账号下发/编辑以及批量上传用户弹窗中，当选中的角色**仅包含质检员**（未选出题角色）时，题目上传上限、日/月请求上限与月预算等输入框及提示说明**整体自动隐藏/不显示**，交互表现保持一致。

**人工质检修正结论审核流优化**

- **质检修正通过后防重跑**：当管理员审核通过质检员提交的参考答案/解题思路修正结论（应用纠正）后，题目保持合格完成状态，不再重新重置为 pending 并自动触发二次 AI 质检/难度分级评测。
- **质检员分配全覆盖**：质检任务中心【分配质检员】下拉框兼容并全量覆盖项目下具备质检员身份的复合账号，方便灵活分派任务。

**页面操作按钮规范统一**

- **全站顶栏按钮尺寸一致**：统一【项目管理】、【用户管理】、【项目用户管理】、【模型与分级策略】等所有管理页面顶栏操作区域（如“创建项目”、“调用成本”、“批量上传”、“下发新账号”等）的按钮尺寸规范为标准 middle 格式，提升界面整体美观度与舒展感。

发布日期：2026-08-25 (按 Commit 提交日期划分)

**题目详情与版本结果一致性**

- 题目保存为新版本后，详情页的当前分级结果只读取当前版本及当前分级任务，不再回退展示上一版本的 L0/L1/L2/L3 结果；旧版本结果仍完整保留在历史质检记录中。
- 修复题目列表显示“未定级”、详情页却显示旧版本定级结果的不一致问题，当前状态与列表、详情统一。

**题目导出基础检测结果**

- 修复导出题目时“LaTeX格式结果”和“LaTeX格式详情”大量为空的问题；导出改为读取当前分级评测 L0 的权威格式检测结果，无错误时详情明确显示“无错误”，有错误时展示具体原因。
- LaTeX 格式结果统一输出中文状态，如“通过”“不通过”“待检测”“检测中”“需人工复核”和“检测失败”。
- AI 合成题结果统一输出中文业务结论：“原创”“疑似合成”“需人工复核”或“检测失败”，不再导出 `pass`、`fail`、`warning` 等英文状态。

**项目成员提交量统计**

- 项目用量与成员消耗明细新增“提交题目数”，独立于“提交质检次数”展示每位成员在当前项目中实际提交的题目数量，便于同时衡量出题贡献与质检消耗。
- 全局项目成本大盘展开项目后同步展示该指标；统计严格限定当前项目，跨项目题目不会混算，无提交记录的项目成员显示为 0 题。

- 公式校验更讲道理了：合法简写不再误报，只拦真正的书写错误；详情页公式显示也更完整。
- 修复相似题检测占用配额的问题：相似题检测是系统自动触发的，不再占用日上限、月上限、月预算和质检次数。之前因配额卡住、一直显示"检测中"的题目会自动恢复。
- 批量上传用户改为逐行设置密码：Excel 模板改成"用户名、密码"两列，密码不合规会在提交前直接指出。
- 项目进度改按合格题数统计：项目卡片和题目列表的目标进度，现在以真正合格的题目数（基础检测通过、分级完成、难度达标）为准。
- kimi 模型提速：提高了并发额度，并适配官方新接口，评测跑得更快更稳。

# v0.0.13

发布日期：2026-08-11

- 新功能：项目级模型设置。每个项目可以单独配置检测模型和分级策略，不配置就自动跟随全局，也能一键改回跟随全局。
- 新功能：分段计价。模型支持按用量分档定价和缓存命中折扣，成本核算更精细准确。
- 修正分层开关的定级口径：关掉某一层后，题目在最高启用层达标就直接定级该层，不会再被错误地降一级。
- 修复模型"返回成功但内容为空"影响分级的问题：这类情况会自动重试，重试仍失败转人工复核，不会再产出错误的难度定级。

# v0.0.12-2

- 新功能：相似题检测总开关。管理员可一键开关相似题检测，即时生效；关闭后上传直接放行，不再阻塞质检流程。上传时的本地快速查重不受影响。
- 修复题目导入整体失败的故障，导入失败时的提示也更易懂了。
- 列表与详情页的合成题判定口径统一，"我的项目"页按钮样式统一。

# v0.0.12

- 稳定性提升：后台评测进程能自我发现"卡死"并自动重启，快速接管未完成的任务，解决"看似在线、实际停摆"的问题。
- kimi 模型通道升级：适配上游新通道命名，升级自动完成，无需人工处理。
- 公式校验新增"丢反斜杠"类笔误检测（如把 σ 写成 sigmaa）；校验报告工具支持按项目批量扫描题库、直接扫描 Excel 题目文件。

# v0.0.11

- 安全加固：连续输错密码临时锁定；退出或改密码后旧设备立即下线；强制强密码；题目内容过滤恶意代码；接口文档可一键关闭。
- 配额拦截覆盖更全：重试、自动检测等场景也检查配额，超额提前提示，不再排队后静默挂起。
- 公式校验新增分数缺括号、跨字段丢下标等常见书写问题拦截。
- 完成上线前系统验证：10 个模块 45 项用例、91 条自动化测试全部通过。

# v0.0.10

- 已合格的题目不再重复检测：已定级合格的题目发起质检会被拦截，避免浪费配额；保存新版本后自动解除。
- 配额改按"质检次数"计数：一次质检无论调用多少次模型只算 1 次；相似题检测和已取消的任务不占配额。
- 公式校验对齐规范红线，修复多处误报，报错带行号更好定位。
- 合成题检测能识别"孤立数字、内容残片"等无效内容，阻断定级并说明原因。
- 重新检测自动复用历史已完成的结果，只重跑失败项，节省配额。
- 答案等价判定逻辑升级，判定更准。

# v0.0.9

- 难度分级取消流程闭环：取消后状态正确复位、可重新检测，修复详情页卡"评测中"的问题；删除题目会先取消在途任务，成本记录不丢失。
- 空答案处理更合理：整层无有效答案时按"0 答对"正常判定，不再误报评测失败；评测失败时详情页清晰展示原因。
- 详情页状态实时更新；重新检测按钮点击后立即置灰，防止重复创建任务。
- 相似题检测：上传时即拦截高度相似的题目并指出相似对象；历史题目补做检测。
- 题目列表新增难度等级筛选；合格口径统一为"基础检测通过且难度达标"。
- 体验细节：提示框显示更久、悬停可暂停；修复顶部标签偶发点不动的问题。

# v0.0.8

- 项目管理员体系完善：可下发、编辑本项目内用户，查看本项目用量，删除自己所在项目。
- 项目支持删除（删除后全局不可见）；可给个人设置上传题目上限，超额提示剩余数量。
- 支持 Excel 批量导入用户、填写手机号。
- 用量与成本治理：账号可设日上限、月上限、月预算，超额任务自动等待、额度恢复后继续；成本统计计入思考部分；评测卡片新增"用量"按钮查看单次成本明细。
- 难度分级：AI 合成题检测并入 L0 门控；分级改为手动触发；判定规则可配置并带校验。
- 队列可靠性：管理员可取消任务；修复任务重复派发、结果被覆盖等问题。
- 模型调用：合成题检测切换更快模型；解题输出上限可在管理页配置；上游报错翻译成人话。
