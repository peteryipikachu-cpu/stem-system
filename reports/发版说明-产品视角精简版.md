# STEM 题目审核系统发版说明（产品视角精简版）

# v0.0.18-dev-rc1

发布日期：2026-08-14

覆盖范围：v0.0.17-dev-rc1 发布后的全部更新

**题目导入与规范**

- 导入区的固定表头改为蓝色标签高亮展示，所见即实际可识别的列；仍支持 `.xlsx`、`.xls`、`.csv`。
- 上传规范继续收紧：题干为“是否/能否/成立吗”等封闭式二值问法会直接拦截，避免模型被迫输出“是/否”而误判；参考答案中未用公式定界符包裹的裸 LaTeX 公式也会拦截。
- 存量题进入分级前同样会经过上述 L0 兜底校验，不合规题目不会再消耗 L1 及以上的模型调用。

**导出与用量追溯**

- 题目导出升级为字段勾选：默认增加出题人，可按需附带各层作答的模型、耗时、Token、思考过程、结果与正确性；跑数明细独立成工作表，更便于阅读和分析。
- 有勾选题目时只导出勾选项，未勾选时保持按当前筛选导出；导出文件名附带时间，连续导出不会覆盖混淆。
- 列表操作范围更清楚：勾选后“质检”和“导出”都会明确显示已选数量；未勾选时导出当前筛选结果，质检按钮会提示先勾选，避免“全部质检”文字与实际范围不一致。切换项目后，上一项目的勾选不会带入新项目。
- 被相似性检测锁定、正在质检或项目暂停中的题目仍可勾选并导出；发起质检时系统会自动跳过暂不可检的题目并说明原因，已锁定题目不会再阻塞正常导出。项目管理员也可在其项目范围内导出。
- 复用历史成功作答时，用量明细会标记“继承·未新调用”，明确说明该行不新增调用次数和成本。

**导入完成提示**

- 导入时如有题目因格式规范或相似性被拦截，会在页面级提示中汇总展示原因；点击“知道了”即可稳定关闭提示并刷新题目列表，不再出现关闭后页面遮罩、滚动或布局异常。

**评测与难度分级**

- L2 改为三段定级：答对 `≤3` 次晋级 L3，答对 `4–5` 次定级 L2，答对 `≥6` 次退回 L1；配置页可查看和调整“晋级 L3”与“退回 L1”两条门槛，评测结果卡同步展示实际分流。
- 部分模型作答失败或返回空答案时，其余有效作答仍继续比对和定级，空答案按答错计入；只有整层均无法完成才判为评测失败。失败原因会直接显示在层级卡中。
- 思考过程支持按需查看全文，不再受评测汇总截断限制；普通用户不再看到或可直接访问调用用量，管理员和项目管理员仍可追溯完整明细。

**稳定性与体验**

- 修复重复派发或迟到失败覆盖已定稿评测结果的风险，并提供历史脏数据修复工具，已完成的真实结果更可靠。
- 登录后的页面右上角统一展示当前用户与退出入口。
- 题目列表分页默认每页 10 条、最小可选 5 条并居中显示；分页及组件内置文案统一为中文。界面组件同步适配 Ant Design 6，提示信息会继承系统主题和本地化设置。

# v0.0.17-dev-rc1

发布日期：2026-08-14

覆盖范围：v0.0.16-dev-rc3 未收录的 08-12 晚间至 08-14 变更（含 08-12 晚间、08-13 全天提交）

**题目导入导出**

- 导出导入打通：导出表头对齐导入固定表头（"问题"列及标题/解题思路列），导出的文件可以直接重新导入；导入预览表补全全部字段列（答案、解题思路截断展示），预览弹窗加宽，上传前一眼看清内容。
- 上传规范全面拦截：导入时逐条校验题型、单题单问、答案约束，编辑保存同一口径拦截防绕过；被拦截条目的违规原因在导入弹窗逐条列出，上传区同步提示规范要求。
- 参考答案列只放最终结果：答案中出现"所以、因此、故、设、代入、解得"等推导连接词或多行推导视为解题思路混入答案列，上传时拦截；导入弹窗补充填写提示（答案只放最终结果、解题思路放解题思路列）。

**评测与策略**

- 分级策略新增"层级流转"开关（全局与项目级均可配置）：开启后题目在某层未达答对门槛也继续流转下一层，全部层跑完后按通过的最高层定级；随任务快照固化，不影响进行中的任务。
- 项目合格题数达标自动暂停：分级评测定级后按合格题数实时判定，达标即自动暂停项目，不再按上传总数误暂停；与之配套的"上传上限按项目目标合计校验"旧逻辑同步下线。
- 队列监控新增"容量实况"卡片（管理员可见）：展示峰值并发对比配置上限、RPM/TPM 实况、429 次数、p95 耗时与上游限流头实证档位，网关额度用没用满一眼看清。
- 空答案作答不再重跑：重新检测时，历史上已完成但无有效答案的作答直接继承、按答错计，不再浪费上游配额重跑。
- 合成题检测识别"大题拆小题"：依赖缺失上下文或前序小问、单独看题意不完整的拆分题，视为 AI 合成痕迹的重要证据。

**公式校验与显示**

- LaTeX 白名单系统性补全（TeX 原子原语、定界符别名、amssymb 逻辑/高阶关系、物理单位符号、常用函数名与文档命令等），大批合法公式不再误报"未知命令"；相邻花括号组规则豁免上/下标正常拼接写法，真正的丢 `\frac` 笔误仍拦截。
- 修复详情页跨行独立公式（`\[...\]`）被按行拆散退化为原文的显示问题。

**修复与体验**

- 修复项目级模型设置保存时偶发 500（保存后读取更新时间报错）的问题。
- 修复系统深色模式下页面背景变黑的问题（误引入的样式模板块已清理）。
- 列表与详情页的质检徽标判定口径统一：以分级评测 L0 权威结论为准，消除两处显示不一致。
- 模型设置页错误提示更可读：上游返回非 JSON 错误正文（如纯文本 500）时不再报错乱码，展示可读的 HTTP 状态与原文。
- 统计口径更透明：项目卡片与调用成本弹窗补充统计口径说明（含已删除题目的历史调用、失败重试均计入成本）。
- 前端工程：构建提速（依赖缓存 + 增量构建缓存 + 国内 npm 镜像）。

**内部工程（界面不可见）**

- 四类模型提示词（解题作答/合成题检测/答案比对/相似题比对）统一拆分为 system/user 下发，并声明题目内容为不可信输入——题干或答案里夹带的异常指令（如要求改判结果、宣称自己不是 AI 合成）不会干扰审核结论。
- Worker 新增并发版难度分级评测基准脚本（层间并发作答、自动产出用量与分层结果报告），用于评测性能验证。
- 模型派发参数留痕日志：可核对治理配置（如解题输出上限）是否真实下发到网关。
- claude-sonnet-5 思考参数经多轮探针验证保持现行口径（adaptive + effort），网关通道思考参数不透传的问题已出具完整问题报告，待网关方处理。

# v0.0.16-dev-rc3

发布日期：2026-08-13

- 模型调用不再设超时：长思考题型的模型调用会一直保持连接，直到回答完成或达到输出上限；此前思考超过约 1 小时会被客户端超时断开的线上问题已修复。
- 分级策略编辑器移除"单次超时"输入框：该配置已无实际作用，界面同步清理；历史策略里保存的旧配置自动忽略，无需处理。
- 队列监控的调用明细列只展示模型名，去掉了多余的厂商标签，界面更简洁。
- 失败原因直接可见：分级评测判败时，失败横幅与评测用量弹窗会展示未成功作答的具体错误摘要（如网关额度不足、调用被中断等），排障不用再查数据库。
- 中断消耗如实记账：发布重启打断的模型调用，用量里不再记成 0 消耗，会按已接收到的流式进度估算计入成本（含思考部分），成本统计更贴近真实花费。
- 历史质检记录可追溯：题目详情页为管理员和项目管理员新增"历史质检任务"列表（项目管理员仅可见其所属项目内的题目），重新质检后旧的跑测记录不再消失，每条可查状态、结果、定级、调用次数与成本，并可点开查看该次任务的详细用量。
- 用量弹窗可看模型产出：展开任意一行调用记录，即可查看该次调用的答案内容、思考过程、比对等价判定或合成检测结论，核对用量时不用再翻工作项明细；失败/中断的调用行默认展开，排障目标一眼可见；长答案/长思考只展示预览，点“查看全文”在侧边抽屉阅读，弹窗里不再套滚动条。
- 经探针验证确认 kimi 模型通道正常（kimi/kimi-k3），此前"旧通道不可用"的记录已更正，无需调整现有配置。
- 批量上传用户支持统一设置题目上传上限：弹窗“统一配额设置”新增“题目上传上限（道）”，留空不限制，对本批次所有账号生效。

# v0.0.14-dev-rc1

# v0.0.13
