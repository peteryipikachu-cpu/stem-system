# STEM 题目审核系统 v0.0.13 发版说明

发布日期：2026-08-11　|　覆盖范围：v0.0.12 之后至 08-11 13:40 的变更（08-08 ~ 08-09 无变更）

本版本围绕「成本治理精细化」与「分级可靠性」两条主线：新增项目级模型设置与分段计价能力，修复分层定级与模型调用异常两类影响评测结论正确性的问题。

## 🗂️ 新功能：项目级模型设置

- **模型管理页支持配置范围切换**：全局范围与「全局 + 各项目」范围可在页头一键切换，每个项目提供独立的模型与策略配置入口。
- **项目自定义范围**：可自定义检查项模型（AI 合成题检测、相似题确认）与 L1/L2/L3 分层策略（模型、Pass@K、答对阈值、每层启用状态），并一键回退到跟随全局。
- **继承与快照规则**：项目未配置时自动继承全局；已配置部分与未配置部分在保存前均视为继承全局。任务创建时快照生效，不影响运行中的任务，项目配置删除后新任务自动回退全局。
- **L0 合成题检测模型**：优先使用项目级设置，未设置时兜底全局设置，两处口径保持一致。

## 💰 新功能：分段计价与缓存命中折扣

- **模型管理支持分段计价配置**：计价方式列 + 分档编辑弹窗，默认按输入 Token 数自动分档（如 gemini-3.1-pro-preview 与 qwen3.7-plus 两档计价），支持缓存命中折扣价。
- **结算按真实输入选档**：Worker 派发时快照分档配置，结算按真实输入 Token 数选择对应档位回写调用台账，历史价格固化、不追溯重算。
- **治理配置校验**：分段配置经 normalize 校验，非法档位直接拒绝保存。

## ⚖️ 修正：分层启用开关的定级口径

- **定级口径修正**：最高启用层满足答对门槛时直接定级该层（此前停用高层会错误降一级）；仅不满足门槛才降一级定级（题目过易的合理口径）。
- **启用开关体验完善**：启用开关增加悬停说明（启用/停用/锁定三态语义）；停用某层自动级联停用后续层；前层停用时后层锁定不可启用，保证启用层自 L1 连续。仅影响之后创建的新任务。

## 🚨 修正：模型「空完成」异常识别

- **问题背景**：kimi/kimi-k3 偶发上游返回"成功"响应但无答案、无思考内容（usage 有 Token），此前被当作空答案=答错计入 K，误推动层级晋级、污染难度分级。
- **识别为调用错位**：此类响应现被识别为 `empty_completion` 可重试协议异常，自动按指数退避重试，台账与评测明细记录异常原因。
- **不再误判难度**：重试耗尽后整层记为异常（未成功完成的作答不代入答对阈值 K），评测整体转人工复核，避免误定级；历史空完成作答不再进入增量复用继承，重跑会重新发起调用。
- **口径边界明确**：有思考无答案（完成但无结果）仍按答错口径处理并可继承复用；仅内容与思考均空才属调用错位。

## 🧩 稳定性：kimi/kimi-k3 网关兼容

- kimi/kimi-k3 三场景（解题/比对/合成题检测）显式传 `enable_thinking=true`，避免上游网关缺省时不返回思考/答案内容。
- 解题阶段保持流式调用（曾短暂因网关 SSE 异常改用非流式，现已恢复流式）；配合 3600 秒读取超时保障长思考响应完整接收。
