# STEM 题目审核系统 v0.0.11 发版说明（增量补充）

发布日期：2026-08-07（当日安全加固版之后的新增内容）

## 🩺 新功能：健康巡检（管理员）

- 新增"健康巡检"页面：实时扫描系统中滞留、卡死、丢失风险的任务，按严重程度列出异常清单（相似题检测卡死、队列项丢失、队列残留、任务阻塞停滞、长时间排队等）。
- 支持一键修复：对可安全处置的异常提供人工修复入口，修复动作带状态守卫，不会误伤运行中的任务。
- 系统自愈配合：相似题检测卡死、队列终态残留等问题会被自动清理，减少人工介入。

## 🛠️ 功能优化

- **相似题检测不再卡死**：检测失败会明确落为"失败"状态并提示，管理员可核查后解除锁定或重跑，题目不再永久停在"检测中"。
- **L0 检测更严谨**：历史格式校验失败的结果不再被复用，重检时按最新规则重新检测，避免旧结论误导定级。
- **导入顺序优化**：上传时优先校验个人上传上限，再执行相似题去重，提示更直接。
- **公式校验规则放宽**：全角波浪号、带圈数字在公式内视为合法，正文 Markdown 标题不再误拦，降低误报。

## 🎨 体验优化

- 修复项目卡片按钮在窄屏下溢出卡片的问题。
- 修复弹窗显示/隐藏触发搜索栏按钮折行错位的问题。

## ⚙️ 工程与部署

- 部署链路硬化说明落地：全链路 HTTPS、数据库加密连接、密钥经 Secret 挂载不落明文、容器以非 Root 用户运行并启用只读文件系统。
- CI 测试阶段配置独立的 Redis 与数据库服务容器，流水线自测更稳定。
- 修复部分镜像源下依赖安装报错的问题。

## ✅ 质量验证

- 后端自动化测试全量通过（96/96，新增健康巡检回归用例）。
