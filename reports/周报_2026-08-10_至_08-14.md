# 工作周报 · STEM 题目审核系统

**周期：** 2026-08-10 ～ 2026-08-14　　**汇报人：** 皮卡皮卡丘

---

## 本周概述

本周围绕“项目级策略配置、题目质量把关、评测可靠性和成本透明化”持续迭代：上线项目级模型与分级策略、分档计价、层级流转和可配置合格标准；打通题目导入导出与历史质检追溯；完善上传规范、LaTeX 校验、异常作答处理及队列容量观测，让配置更灵活、结论更可靠、用量与成本更清晰。

## 新功能

### 1. 项目级模型与分级策略

- 模型管理页新增全局与项目配置范围，每个项目可独立设置 AI 合成题检测、相似题确认模型及 L1/L2/L3 分层策略。
- 未做项目配置时自动跟随全局，已自定义项目可一键恢复跟随全局；任务创建时固化配置快照，不影响运行中任务。
- 分级策略新增“层级流转”开关：开启后，某层未达门槛也可继续评测下一层，最终按达标的最高层定级，减少单层偶发失手导致的难度低估。
- 题目合格最低难度支持按全局或项目配置（L1/L2/L3），列表、详情、项目进度和重检门控统一使用同一合格口径。

### 2. 项目目标按合格题管理

- 项目进度由“已上传题数”调整为“合格题数”，项目卡片和题目列表同步展示。
- 分级评测定级后实时统计合格题，达到项目目标时自动暂停项目，避免超额生产。
- 下线与新口径冲突的“按上传总数校验项目目标预算”旧逻辑。

### 3. 分档计价与容量实况

- 模型配置支持按输入 Token 数分档计价及缓存命中折扣，结算时按真实用量选档，价格随任务快照固化，历史费用不追溯重算。
- 管理员队列监控新增“容量实况”，展示各厂商峰值并发、RPM/TPM、429 次数、p95 耗时及上游限流头信息，为容量调整提供数据依据。

### 4. 题目导入导出升级

- 导出表头与导入模板对齐，导出文件可直接重新导入；导入预览补全问题、答案和解题思路等字段。
- 导出新增字段勾选弹窗，支持导出出题人与每层跑数明细；跑数结果在独立工作表中逐行展示模型、耗时、Token、思路、答案和判定结果。
- 已勾选题目时精确导出勾选项，未勾选时按当前筛选范围导出；文件名增加时分时间戳，便于区分同日多次导出。

### 5. 历史质检与用量追溯

- 题目详情页为管理员和项目管理员新增“历史质检任务”卡片，重新质检后仍可查看旧任务的状态、结果、定级、调用次数和成本。
- 用量弹窗支持展开查看模型答案、思考过程、等价判定和合成检测结论；失败或中断记录默认展开，超长内容可在侧边抽屉中查看全文。
- 继承的历史作答以“继承·未新调用”明细展示，并明确说明不计入当次调用次数和成本。
- 详情页“查看思考过程”改为按需读取落库全文，解决超长思考内容被截断的问题。

## 改进与优化

### 1. 题目上传规范把关

- 导入时逐题校验题型、单题单问和答案规范，不合规题目不导入，并在导入弹窗逐条说明原因；编辑保存新版本使用同一口径，防止绕过。
- 新增对解答题/计算题类型、多小问、选择/判断/证明类题干、近似答案、特殊短答案、解题过程混入答案列等问题的拦截。
- 进一步拦截“是否/能否/成立吗”等二值闭合问法，以及参考答案中未被定界符包裹的裸 LaTeX 公式，避免问法误导模型或公式无法正确渲染。

### 2. LaTeX 校验与公式显示

- 按“合法 TeX 语法不拦、只拦真缺陷”放宽校验，支持 `\mathbb F_2^4`、`\sqrt x`、`\frac13` 等合法简写。
- 系统性补全 TeX 原子原语、定界符别名、amssymb 逻辑/关系命令、物理单位符号、常用函数和文档命令白名单，降低未知命令误报。
- 修复 `\(...\)`、`\[...\]` 闭合扫描、公式内竖线被误当表格分隔符，以及详情页跨行独立公式被拆散显示为原文等问题。

### 3. 评测与模型调用

- 修正分层启用开关的定级语义：最高启用层达标时直接定级该层，不再错误降一级；停用某层时自动停用后续层，保证启用层连续。
- 作答最终口径调整为：空答案按答错计入 K，少量作答失败不阻断比对和定级，仅整层作答全部失败时才判定该层失败；层汇总同步展示未成功作答原因。
- 重新检测时继承已完成的历史作答（包含空答案），空答案按答错处理，避免重复消耗上游配额。
- 移除模型读取超时和已失效的“单次超时”策略配置，长思考题保持连接至回答完成或达到输出上限。
- kimi 默认厂商并发由 2 提升至 6，并适配 `max_completion_tokens` 等新网关参数；Claude 解题采用现行 `adaptive + effort` 思考参数口径。
- 合成题检测补充“大题拆小题”识别，将依赖缺失上下文或前序小问、无法独立理解的题目作为重要识别信号。

### 4. 配额、账号与界面体验

- 系统自动触发的相似题检测不再受日上限、月上限、月预算和质检次数限制，也不消耗这些额度；存量卡住的任务可自动恢复。
- 批量上传用户模板调整为“用户名、密码”两列，每行独立设置密码并校验复杂度；支持为整批用户统一设置题目上传上限。
- 用量与成本数据收紧为管理员和项目管理员可见，普通用户页面不再展示用量入口，直接访问接口也会被拒绝。
- 题目列表分页支持切换每页条数；所有登录后页面的右上角统一展示当前用户信息。
- 修复系统深色模式下页面背景变黑、已删除项目在账号编辑弹窗显示裸 ID 等界面问题。

## 问题修复与稳定性

- 修复项目级模型设置保存后读取更新时间偶发 500 的问题。
- 统一列表、详情和版本汇总的质检徽标口径，以分级评测 L0 的最新权威结论为准，消除前后展示不一致。
- 迟到的失败回执增加终态校验，不再覆盖已完成的工作项结果；同步提供历史脏数据修复工具。
- 发布重启打断的流式调用按已接收的答案与思考进度估算部分消耗，避免真实调用被记为 0 成本。
- 分级失败横幅和用量明细直接展示网关额度不足、调用中断等具体错误摘要，降低排障成本。
- 模型设置页对非 JSON 错误响应增加容错，直接展示 HTTP 状态和原始错误摘要，避免二次解析报错。

## 安全与工程建设

- 解题作答、合成题检测、答案比对和相似题比对四类提示词统一拆分为 system/user 消息，将规则与题目内容分离，并明确将题干和答案视为不可信输入，降低题目内容干扰审核结论的风险。
- Worker 新增并发版难度分级评测基准工具，可自动产出分层结果和用量报告，用于性能与策略验证。
- 模型派发参数增加留痕日志，可核对治理配置是否真实下发到网关；完成 Claude 思考参数的多轮通道探针和问题报告。
- 前端 CI 改为增量复用 `node_modules` 与 Next.js 构建缓存，并使用国内 npm 镜像；后端和 Worker CI 统一使用阿里云 PyPI 镜像并增加重试，提升构建稳定性。
